al-muslim

the mobile project

al-muslim is built to stay calm and direct. no ads. privacy first. fast where it matters. the goal is simple: keep the experience focused, respectful, and ready for daily use without noise.

01

real-time prayer

handles all the math locally. your location never leaves your device. accurate schedules, no waiting, and no clutter.

02

clean quran

high-contrast reading, straightforward playback, and fast search built for actual daily use instead of distraction.

03

privacy first

no ads and no telemetry layer shaping the experience. what matters stays local and direct.

04

fast by default

a quiet interface is only useful if it responds instantly. the app is tuned to stay light and quick.

mobile stack

  • framework: react native + expo
  • database: sqlite
  • privacy: zero external telemetry

al-muslim for linux

the official linux branch is now live as version 1.0v. it includes a standalone qt desktop app and a kde plasma widget, keeping prayer times, quran playback, and the hijri date close to the desktop with the same quiet direction as the mobile release.

01

desktop app

standalone qt desktop app built for linux with a direct, low-noise interface.

02

kde widget

ships with a kde plasma widget so the essentials stay visible without opening the full app.

03

languages

04

release artifacts

the current linux artifact is ready for download alongside the public source repository.

linux project layout
